# A.T Matrix Product Website

Standalone draft website for A.T Matrix consumer product concepts.

The site deliberately focuses on product discovery and validation. ARGUS, education and internal company documents are kept outside this repository so each website can maintain a clear audience and search intent.

## Included concepts

- Rhythm Grove
- Tiny Rescue
- Weather Windows
- Pocket Shark

## Local preview

Serve the repository root with any static web server, for example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment note

The canonical URL and sitemap currently target the repository's expected GitHub Pages URL. Update both if the final product website uses a custom domain.
